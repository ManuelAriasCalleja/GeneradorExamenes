Generador de exámenes tipo test
===============================

1. Descomprima la carpeta GeneradorExamenes entera donde quiera (por ejemplo, en Documentos). No saque el
   programa de ella: necesita los demás ficheros que la acompañan.

2. Abra GeneradorExamenes.exe. La primera vez, Windows puede avisar de que el programa es de un editor
   desconocido: pulse «Más información» y después «Ejecutar de todas formas».

3. El programa pregunta por el banco de preguntas (un fichero .db) o si quiere crear uno nuevo. Las preguntas
   no vienen con el programa.

4. Para ver cómo se usa, pulse F1 o abra Ayuda → Manual de uso.

La ruta del último banco abierto y las opciones se guardan en %APPDATA%\UNED\GeneradorExamenes.ini.
Para pasar a una versión nueva, borre esta carpeta y descomprima la nueva: la configuración se conserva.
