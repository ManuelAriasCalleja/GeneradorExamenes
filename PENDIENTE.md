# Mejoras pendientes

Propuestas aceptadas el 22 de octubre de 2026, por orden de prioridad. Se van haciendo de una en una; al
terminar cada una, se quita de aquí.

1. **Copia de seguridad automática** de la base de datos antes de «Importar → Reemplazar todo», que borra
   todos los temas y preguntas.
2. **Una sola fuente de las preguntas.** La base de datos y `asignatura/BancoPreguntas/preguntas_fi.json` se mantienen a mano por
   separado. Que el programa avise cuando no coincidan, o que actualice el JSON él solo.
3. **Windows: paquete para otros ordenadores**, un zip o instalador preparado con `windeployqt`. (El programa ya no
   depende de rutas fijadas al compilar: pregunta por el banco si no lo encuentra.)
4. **Duración, al diálogo de práctica.** El campo «Duración» de la convocatoria ya solo sirve para el reloj de
   «Practicar este examen…».
5. **Versión adaptada con letra grande**, para estudiantes con discapacidad visual (el contrario de los niveles
   de compactación de la maqueta).
6. **Exportar el banco a cuestionarios de Moodle** (XML o GIFT), para practicar en el curso virtual si la
   plataforma los admite.
