# Mejoras pendientes

Propuestas aceptadas el 22 de octubre de 2026, por orden de prioridad. Se van haciendo de una en una; al
terminar cada una, se quita de aquí.

1. **Una sola fuente de las preguntas.** La base de datos y `asignatura/BancoPreguntas/preguntas_fi.json` se mantienen a mano por
   separado. Que el programa avise cuando no coincidan, o que actualice el JSON él solo.
2. **Duración, al diálogo de práctica.** El campo «Duración» de la convocatoria ya solo sirve para el reloj de
   «Practicar este examen…».
3. **Versión adaptada con letra grande**, para estudiantes con discapacidad visual (el contrario de los niveles
   de compactación de la maqueta).
4. **Exportar el banco a cuestionarios de Moodle** (XML o GIFT), para practicar en el curso virtual si la
   plataforma los admite.
